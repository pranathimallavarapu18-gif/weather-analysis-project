# Atmosphere — Professional Weather Web App 🌦️

A modern, glassmorphism-styled weather application powered directly by **Open-Meteo** and **OpenStreetMap Nominatim** APIs.

---

## ✨ Features

- 🔍 **Live Search with Autocomplete**: Search any place, city, landmark, or region across the world.
- 📍 **GPS "My Location"**: Instant 1-click current weather detection.
- 🌡️ **Interactive Metrics**:
  - Current Temperature with animated weather badges.
  - Feels Like, Humidity, Surface Air Pressure, Wind Speed & Compass Direction.
  - UV Index Exposure Rating.
  - Sunrise & Sunset daylight progress tracker.
- ⏱️ **24-Hour Forecast**: Scrollable timeline for the next 24 hours with precipitation chances.
- 📅 **7-Day Extended Forecast**: Daily visual temperature min/max range bars and conditions.
- 🗺️ **Interactive Map**: Embedded Leaflet map with exact pin and direct Google Maps link.
- 🔄 **Unit Switcher**: Instant 1-click switch between **°C (km/h)** and **°F (mph)**.
- 🎨 **Dynamic Atmospheric Theme**: Auto-adapts colors and backdrop glow based on weather (Clear Day/Night, Rain, Snow, Clouds, Storm).

## 🚀 How to Run

### Option 1: Direct Browser Launch (No server needed)
Simply double-click [`index.html`](file:///C:/Users/pranathi/.gemini/antigravity/scratch/weather-web-app/index.html) or open it in any web browser (Chrome, Edge, Firefox, Safari).

### Option 2: Run via Python Server
```bash
python server.py
```
This will automatically start a local server at `http://localhost:8000` and open it in your default web browser.
